# TimeGleam Brand Voice

## Identity

- 产品：拾光 TimeGleam；英文名 TimeGleam，可执行文件 `timegleam`。
- 官网与账号：https://timegleam.com 。
- 品牌主色：金色 `#E0A64B`；底色 `#121110`。
- 桌面应用 ID：`com.timegleam.desktop`；深链协议 `timegleam://`。
- npm scope：`@hy`；镜像仓库：`ccr.ccs.tencentyun.com/lucky/<name>`。

## Model and service naming

- 对话与图像请求统一经 timegleam.com 代理，模型列表由线上目录决定。
- 对外文案只写模型在目录中的展示名；不得出现上游厂商名、权重格式或 `qwen*` 痕迹。
- 计费按线上账本记录；文案提到用量时写「额度 / credits」，不要暴露内部分点或单位换算。

## Product names

| 产品 | 标识 | 入口 |
|---|---|---|
| 桌面应用 | 拾光 TimeGleam | `timegleam.exe` / `com.timegleam.desktop` |
| 在线服务 | TimeGleam | https://timegleam.com |
| 桌面登录 | TimeGleam 账号 | https://timegleam.com 授权页 |
| 深链 | `timegleam://open`、`timegleam://project/<id>` | 系统浏览器或应用内 |

## Voice

- 中文文案以「拾光 TimeGleam」首次出现，「拾光」或「TimeGleam」其后单独出现。
- 英文文案使用 sentence case；产品名保持 `TimeGleam` 的驼峰拼写。
- 陈述能力用现在时，直接说明能做什么、数据在哪里、失败时如何恢复。
- 不自行发明口号或数据承诺；涉及额度、计费与隐私时以 timegleam.com 的现行说明为准。
